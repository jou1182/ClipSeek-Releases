## 🇸🇦 العربية

### لماذا ClipSeek؟

هل تذكرت كلمة أو مصطلحًا قاله المعلم في إحدى الحلقات ولا تعرف أين؟ بدل إعادة مشاهدة عشرات الدروس، اكتب الكلمة وستجدها في **ثوانٍ** — مع القفز بالفيديو إلى **اللحظة الدقيقة** التي نُطقت فيها.

| ✅ | ✅ | ✅ |
|---|---|---|
| ابحث في كل الحلقات دفعة واحدة | نتائج فورية أثناء الكتابة | قفزة دقيقة إلى كلمة في الفيديو |

### ✨ أبرز الميزات

| الميزة | الوصف |
|---|---|
| ⚡ **بحث فوري** | النتائج تظهر أثناء كتابتك — بلا ضغطة زر |
| 🔍 **بحث بعبارات** | اكتب `"قواعد البيانات"` لتجد العبارة كاملة كوحدة واحدة |
| 📚 **مكتبة المجلدات** | أضف كل سلاسل حلقاتك وابحث فيها معًا |
| 📊 **ملخص الحلقات** | اعرف أي حلقة تكررت فيها الكلمة أكثر — الأهم أولًا |
| 🕌 **عربي أولًا** | يتجاهل التشكيل والهمزات تلقائيًا (أ/إ/آ ← ا) |
| 🎬 **تشغيل دقيق** | يقفز بالفيديو إلى التوقيت عبر VLC أو MPV |
| 📤 **تصدير** | Excel / HTML / نسخ — بالعربية والإنجليزية |
| 🌓 **ثيمات** | داكن/فاتح + واجهة عربية كاملة (RTL) |

## 🇬🇧 English

### Why ClipSeek?

Remember a word or phrase your instructor said in one of dozens of lessons, but can't recall where? Stop re-watching entire episodes. Type the word — ClipSeek finds it across **all your episodes in seconds** and **jumps the video to the exact moment** it was spoken.

---

### ✨ Highlights

| Feature | Description |
|---|---|
| ⚡ **Live search** | Results appear as you type — no button needed |
| 🔍 **Phrase search** | `"database design"` matches the full phrase as one unit |
| 📚 **Folder library** | Add all your series and search them together |
| 📊 **Episode summary** | See which episode mentions the word most — top first |
| 🕌 **Arabic-first** | Diacritics & hamza-insensitive search by default |
| 🎬 **Precise playback** | Jumps to the exact timestamp via VLC / MPV |
| 📤 **Export** | Excel / HTML / clipboard — Arabic & English |
| 🌓 **Themes** | Dark/Light + full RTL Arabic interface |

---

### 📥 Download & Start

**Step 1 — Download**

From the **[Releases](../../releases)** tab, download `ClipSeek.exe` and run it — no installation required.

> 🛡️ **SmartScreen warning?** The app is unsigned — click **"More info"** → **"Run anyway"**.

**Step 2 — Generate subtitles (with the free Buzz app)**

1. Open [Buzz](https://github.com/chidiwilliams/buzz) and transcribe your episodes
2. Recommended for Arabic: `Faster Whisper` + `Large-V3-Turbo` + `Auto detect` + `Transcribe`
3. Export as **SRT**

**Step 3 — Search!**

1. Put the SRT files next to your videos (same folder)
2. Open ClipSeek → pick the folder
3. Type any word → results stream in → click **"Open"** to jump to the moment

📖 **Full guide:** `USER_GUIDE.md` is attached to every release.
